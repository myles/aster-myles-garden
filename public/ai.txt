# ai.txt

Aster was built by Myles Braithwaite (https://myles.garden) with help
from AI tools.

Tools: Claude, ChatGPT
Used for: code, design assets
Reviewed by: a human (Myles)

The chart calculations come from the Swiss Ephemeris, not from AI.

The site calculates charts in your browser. Aster also has a JSON API,
which runs on a server and uses the same Swiss Ephemeris calculation,
for natal charts, transits, progressions, solar and lunar returns,
comparisons and composites.
Birth details sent to it travel only in the request body, and are
never logged or stored. See https://aster.myles.garden/llms.txt.

AI training: permitted. The source code is public under the AGPL:
https://github.com/myles/aster-myles-garden
